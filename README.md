# YOLOv8 安全帽检测系统

基于YOLOv8的安全帽检查与识别系统，提供图形界面，支持图片、视频和摄像头输入。

## 功能特点

- ✅ 加载YOLOv8模型进行安全帽检测
- ✅ 提供图形界面，支持图片、视频和摄像头输入
- ✅ 显示检测结果和目标位置信息
- ✅ 支持批量处理和结果保存
- ✅ 支持模型训练和自定义数据集

## 目录结构

```
YOLOv8hat-helmet/
├── Font/                 # 字体文件
├── TestFiles/            # 测试文件
├── UIProgram/            # UI界面相关文件
├── __pycache__/          # Python缓存文件
├── datasets/             # 数据集
├── models/               # 模型文件
├── save_data/            # 保存的检测结果
├── CameraTest.py         # 摄像头测试脚本
├── Config.py             # 配置文件
├── MainProgram.py        # 主程序文件
├── TrainProgram.py       # 训练程序文件
├── VideoTest.py          # 视频测试脚本
└── detect_tools.py       # 检测工具函数
```

## 环境要求

- Python 3.9+
- PyQt5
- OpenCV
- Ultralytics (YOLOv8)
- PyTorch
- NumPy
- PIL

## 安装方法

1. 克隆或下载项目到本地
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
3. 在models目录下放置YOLOv8模型文件（.pt格式）

## 使用方法

1. 运行主程序：
   ```bash
   python MainProgram.py
   ```

2. 功能使用：
   - **图片检测**：点击"图片"按钮，选择图片文件进行检测
   - **视频检测**：点击"视频"按钮，选择视频文件进行检测
   - **摄像头检测**：点击"摄像头"按钮，使用默认摄像头进行实时检测
   - **批量处理**：点击"批量处理"按钮，选择文件夹进行批量检测
   - **保存结果**：点击"保存"按钮，保存检测结果
   - **模型训练**：在训练标签页设置参数，点击"开始训练"按钮进行模型训练

## 模型说明

- 默认使用yolov8n-hat.pt模型
- 支持自定义模型，只需将模型文件放在models目录下

## 数据集说明

- 数据集位于datasets/helmetData目录
- 包含测试图片和data.yaml配置文件

## 注意事项

1. 确保models目录中有YOLOv8模型文件
2. 确保Font目录中有platech.ttf字体文件
3. 摄像头检测需要摄像头设备
4. 训练模型需要足够的GPU内存

## 错误处理

- 程序已添加完善的错误处理，当遇到问题时会显示详细的错误信息
- 常见错误及解决方法：
  - 模型文件不存在：在models目录中放置YOLOv8模型文件
  - 摄像头无法打开：检查摄像头是否连接正常或被其他程序占用
  - 视频文件无法打开：检查视频文件格式是否正确
  - 保存失败：检查保存路径是否有写入权限
